## Progressive Disclosure

Antigravity follows a **progressive disclosure pattern**:

1. **Discovery**: Agent sees list of skills with names and descriptions
2. **Activation**: If relevant, agent reads full `SKILL.md` content
3. **Execution**: Agent follows skill's instructions

You don't need to explicitly tell the agent to use a skill—it decides based on context.

## Skill Structure

Each skill follows this structure:

```
.agent/skills/my-skill/
├── SKILL.md       # Main instructions (required)
├── scripts/       # Helper scripts (optional)
├── examples/      # Reference implementations (optional)
└── resources/     # Templates and assets (optional)
```

### SKILL.md Format

Every `SKILL.md` must have YAML frontmatter:

```markdown
---
name: my-skill
description: Clear description of what the skill does and when to use it
---

# My Skill

Detailed instructions for the agent...
```

## Best Practices

1. **Keep skills focused** - Each skill should do one thing well
2. **Write clear descriptions** - Help the agent decide when to use the skill
3. **Use scripts as black boxes** - Encourage `--help` instead of reading source
4. **Include decision trees** - For complex skills, help the agent choose the right approach
