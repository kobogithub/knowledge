# aws-best-practices

AWS cloud infrastructure best practices

## Overview

This skill provides guidelines, patterns, and best practices for working with aws.

## Key Principles

1. **Follow official documentation** - Always reference official docs
2. **Security first** - Consider security implications
3. **Performance** - Optimize for performance
4. **Maintainability** - Write clear, maintainable code
5. **Testing** - Ensure proper test coverage

## Best Practices

### DO

- Write clear, descriptive code
- Follow community conventions
- Document your work
- Test thoroughly
- Review changes before committing

### DON'T

- Skip testing
- Ignore security warnings
- Hard-code secrets
- Leave debug code in production
- Skip code reviews
